# Hospital Management System

## Overview
The Hospital Management System is a Java-based Object-Oriented Programming (OOP) project developed to simplify hospital administration. The system manages patient records, doctor information, appointments, billing, and hospital operations in an organized and efficient manner.

## Features
- Patient Registration
- Doctor Management
- Appointment Scheduling
- Patient Admission and Discharge
- Medical Record Management
- Billing System
- Search and Update Records
- Generate Hospital Reports

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File Handling (MySQL Database)

## OOP Concepts Implemented
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors
- Method Overloading and Overriding
- Exception Handling

## How to Run

1. Clone this repository.
2. Open the project in your preferred Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
3. Compile all Java files.
4. Run `Main.java`.
5. Follow the on-screen menu to use the system.
